# Prompts para Gemini — orden de uso

Se pegan **en orden**. El Prompt 0 va siempre al inicio de cada sesión nueva. Las pantallas de referencia están en `docs/maqueta/pantallas/` (un HTML por pantalla) y los tokens en `docs/maqueta/tokens.css`.

| # | Archivo | Qué arma | Adjuntar |
|---|---|---|---|
| 0 | 00-contexto.md | Reglas fijas | — |
| 1 | 01-andamiaje-y-tokens.md | Proyecto, tokens, modo primaria suave | tokens.css |
| 2 | 02-componentes-compartidos.md | Componentes reutilizables | 1a, 2a, 3a |
| 3 | 03-ingreso-y-consentimiento.md | Ingreso por código, consentimiento | 3d, 3e |
| 4+ | (por redactar) | Diagnóstico (6a-6d), alumno primaria (2a, 2b), docente (1a, 5a, 3a, 3b, 3c, 4c, 5b), familia (3f), luego fase 2 (2c, 2d, 7, 4a, 4b) | — |

Después de cada prompt: abrir la app, revisar móvil y escritorio, mirar la consola, y recién entonces pasar al siguiente. Si hay algo que corregir, hacerlo en el mismo hilo antes de avanzar.
